# CSS Lab

A hands-on way to learn CSS by doing — 28 interactive lessons (HTML and CSS), practice drills, a build-the-page game, a quiz, and a review mode, all in the browser with no download or account.

**Category:** Education

**Live site:** https://islandcoder3.github.io/css-lab/

**Built with:** HTML, CSS, JavaScript

## About

CSS Lab is a beginner-friendly CSS course built around live demos instead of long explanations. Every lesson pairs a short explanation with a "Live demo" you can change using sliders, dropdowns, and checkboxes, plus a readout that shows the exact CSS you just wrote. Each lesson ends with a "Remember" note and a one-question check that must be answered correctly to complete it, so progress actually means something. Any check question you miss is saved to a Review mode that quizzes you on your mistakes until you get them right.

Lessons are grouped into HTML Basics, CSS Basics, Box Model, Layout, Advanced, and Responsive. They start with the page skeleton, headings, links, images, lists, forms, and class and id, then cover the three ways to apply CSS, color formats, units, background and font shorthand, width and height, padding, margin, borders and box-sizing, display (block, inline-block, none, flex), CSS Grid, float and clearfix, positions and z-index, pseudo-elements, :nth-child and selectors, gradients, text styling, border-radius, :hover and transitions, and responsive design with media queries. After the lessons, practice drills ask you to write real CSS, and the page checks your result against the element's actual computed styles rather than comparing text, so any correct answer counts. The capstone, Site Builder Quest, is a 9-level game where you pick the right CSS to build a complete web page, earning stars, badges, and ranks along the way, with a Pro mode for typing the CSS yourself.

The site is data-driven rather than hand-built page by page: lesson demos are wired through a few shared data attributes in one script, while lesson notes, check questions, the quiz, and the cheatsheet live in simple lists. Everything — lesson progress, solved drills, game stars, quiz best score, and theme — is saved to the browser's local storage, so there's no account or backend involved.

## Features

- 28 lessons across 6 groups (HTML Basics, CSS Basics, Box Model, Layout, Advanced, Responsive), each with a live demo, a readout of the code you wrote, a "Remember" note, and a check question
- 15 practice drills that test your CSS against the page's real computed styles, with hints and solutions
- Site Builder Quest: a 9-level game that builds a real page by picking CSS values, with stars, badges, ranks, a goal preview, and a Pro mode for typing it yourself
- Phone-friendly code editing: a tap-to-insert symbol bar and live suggestions for properties, values, and selectors
- Tap-to-inspect preview in the game and Pro mode, showing an element's classes and CSS without browser DevTools
- Review mode that collects the check questions you missed and clears them as you get them right
- Live responsive-design demo: a real page in a frame that switches layout as you change the screen width
- 16-question quiz with a saved best score, and a searchable cheatsheet that links back to each lesson
- Progress saved locally per device, with a reset option
- Dark/light theme toggle and a responsive layout built for mobile as well as desktop

## Tech Stack

Vanilla HTML, CSS, and JavaScript — no frameworks, build tools, or backend required to run it.

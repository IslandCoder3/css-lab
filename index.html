HTML Basics

1. The page skeleton

Every web page is built with HTML. HTML uses tags such as <body> to say what each part of the page is. All pages share the same skeleton.

<!DOCTYPE html>
<html>
  <head>
    <title>My page</title>
  </head>
  <body>
    <h1>Hello!</h1>
    <p>Welcome to my page.</p>
  </body>
</html>

CSS Basics


        

          
1. What is CSS?

          
CSS (Cascading Style Sheets) controls how HTML looks. HTML is the structure, CSS is the paint. Every rule has a selector, a property and a value.

          
selector {
  property: value;
}

          

            
<p style="color: red;">Hello</p>

            
<head>
  <style>
    p { color: red; }
  </style>
</head>

            
<head>
  <link rel="stylesheet" href="style.css">
</head>

/* style.css */
p { color: red; }

5. Units: px, %, rem and vw

          
A size needs a unit. px is fixed. % follows the parent. rem follows the root font size (16px by default). vw is 1% of the screen width. Resize your browser window and watch the numbers.

          
Resize the window: some sizes change, some do not.

Responsive & Interactive


        

          
27. :hover and transitions

          
:hover styles an element while the pointer is over it (on a phone, while it is tapped). A transition makes the change animate smoothly. Hover over the button, or tap it.

          

          

            
            
            
          

          

        


        

          
28. Responsive design

          
A responsive page fits every screen. A media query applies rules only on some screen sizes. This demo is a real page inside a frame. Slide the screen width below 600px and watch the layout switch.

          

          

            
          

          

          
<meta name="viewport" content="width=device-width, initial-scale=1">

.cards { display: flex; gap: 12px; }

@media (max-width: 600px) {
  .cards { flex-direction: column; }
}
